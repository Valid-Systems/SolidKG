# SolidKG Documentation Site

This is the Astro + Starlight documentation site published at https://solidkg.local/solidkg/.

## Development

Run commands from the repository root:

```bash
pnpm --dir site install
pnpm --dir site dev
pnpm --dir site build
```

Docs live in `site/src/content/docs/`. Keep the site copy aligned with the root `README.md` when changing public tool behavior, benchmark claims, or MCP guidance.
